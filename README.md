# DA3408 A4: CPU Image Captioner with Prometheus & Grafana
Streamlit app (BLIP base, CPU) with Single and Bulk (ZIP) modes, prometheus_client metrics on :8000, node_exporter, Prometheus and Grafana.

## Run
```bash
pip install -r requirements.txt
docker compose -f monitoring/docker-compose.yml up -d
python app/main.py
```
| url to access | What is it |
|---|---|
| http://localhost:8501 | Streamlit app |
| http://localhost:8000/metrics | app metrics |
| http://localhost:9090/targets | Prometheus targets (caption_app, node, prometheus) |
| http://localhost:3000/d/da3408-a4-captioner | Grafana dashboard (admin/admin) |

## Files

- `app/`: Streamlit app, BLIP captioner, metric definitions
- `monitoring/prometheus/prometheus.yml`: scrape config (app + node_exporter)
- `monitoring/prometheus/alerts.yml`: alert rules
- `monitoring/grafana/dashboards/caption_app.json`: dashboard JSON export
- `dashboard_recording.mp4`: about 1 minute of the dashboard at 5 s refresh

## AI attribution

Flow from health -> golden signals -> pipeline internals -> clients -> host resources; correlate CPU with bulk uploads; colour-blind-safe palette, named axes with units and scale, legends, titles and descriptions on every panel."
